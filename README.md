# HTML Cheatsheet

A small static website with a practical HTML cheatsheet — browse it online or download it as a PDF.

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | [index.html](index.html) | Landing page with links to the tutorial and PDF |
| HTML Tutorial | [html-tutorial.html](html-tutorial.html) | The full cheatsheet: structure, text, links, images, lists, tables, forms, semantic tags, media, meta tags |
| PDF Version | [pdf.html](pdf.html) | View the cheatsheet PDF in the browser or download it |

All three pages are cross-linked through a shared navigation bar and in-text links.

## Learn more

This cheatsheet is a condensed companion to the full guides on html5andcss3.org:

- [Complete HTML tutorial](https://html5andcss3.org/tutorials/html/)
- [HTML tutorial as a PDF](https://html5andcss3.org/html-tutorial-pdf/)

## Run locally

No build step — just open `index.html` in a browser.

## Files

- `index.html` — home page
- `html-tutorial.html` — HTML tutorial / cheatsheet page
- `pdf.html` — PDF viewer page
- `cheatsheet.pdf` — printable PDF version of the cheatsheet
- `style.css` — shared stylesheet
