1. Document Structure

Every HTML page starts from this skeleton:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Title</title>
</head>
<body>
  <!-- Visible content goes here -->
</body>
</html>
TagPurpose
<!DOCTYPE html>Tells the browser this is an HTML5 document.
<html>Root element; set lang for accessibility and SEO.
<head>Metadata: title, charset, styles, scripts.
<body>Everything the user actually sees.
<!-- ... -->Comment — ignored by the browser.

2. Text & Headings

<h1>Main heading (one per page)</h1>
<h2>Section heading</h2>   ... down to <h6>

<p>A paragraph of text.</p>
<br>                <!-- line break -->
<hr>                <!-- horizontal rule -->

<strong>important</strong>   <em>emphasis</em>
<b>bold</b>                  <i>italic</i>
<u>underline</u>             <mark>highlight</mark>
<small>fine print</small>    <del>removed</del> <ins>added</ins>
<sub>subscript</sub>         <sup>superscript</sup>
<code>inline code</code>
<pre>preformatted block</pre>
<blockquote>a quoted passage</blockquote>
<abbr title="HyperText Markup Language">HTML</abbr>
Use <strong>/<em> for meaning and <b>/<i> for pure styling — screen readers treat them differently.

Example of natural linking: this tutorial links back to the home page and to the PDF version right inside the text, exactly like the snippet above.

4. Images

<img src="photo.jpg" alt="Describe the image" width="400" height="300">

<!-- Responsive image -->
<img src="photo.jpg" alt="..." style="max-width:100%; height:auto;">

<!-- Image as a link -->
<a href="index.html"><img src="logo.png" alt="Home"></a>

<!-- Image with caption -->
<figure>
  <img src="chart.png" alt="Sales chart for 2026">
  <figcaption>Sales grew 40% in 2026.</figcaption>
</figure>
Always write a meaningful alt — it is read aloud by screen readers and shown if the image fails to load.

7. Forms & Inputs

<form action="/submit" method="post">
  <label for="name">Name</label>
  <input type="text" id="name" name="name" placeholder="Your name" required>

  <input type="email"    name="email">
  <input type="password" name="pwd" minlength="8">
  <input type="number"   name="age" min="1" max="120">
  <input type="date"     name="dob">
  <input type="checkbox" name="agree" checked>
  <input type="radio"    name="plan" value="free">
  <input type="file"     name="resume" accept=".pdf">
  <input type="range"    name="volume" min="0" max="100">
  <input type="color"    name="theme">
  <input type="hidden"   name="token" value="abc123">

  <select name="city">
    <option value="mum">Mumbai</option>
    <option value="del" selected>Delhi</option>
  </select>

  <textarea name="message" rows="4" cols="40"></textarea>

  <button type="submit">Send</button>
  <button type="reset">Clear</button>
</form>
AttributeWhat it does
requiredField must be filled before submit.
placeholderHint text shown inside the field.
nameKey used when the form data is sent.
valueDefault / submitted value.
disabled / readonlyField can't be edited (disabled is also not submitted).

8. Semantic Layout

Semantic tags describe what a block is, not just how it looks:

<header>  Site or section header (logo, nav)
<nav>     Navigation links
<main>    The main content — one per page
<section> A thematic group of content
<article> Self-contained content (post, card, comment)
<aside>   Sidebar / related content
<footer>  Footer of the page or a section
<figure> + <figcaption>  Image/diagram with caption
<details> + <summary>    Collapsible section
<div>     Generic block container (no meaning)
<span>    Generic inline container (no meaning)
This very site uses them: view the source of the home page to see <header>, <nav>, <main> and <footer> in action.

12. Global Attributes

These work on almost every HTML element:

AttributePurpose
idUnique identifier — target for links (#id), CSS and JS.
classReusable label for styling multiple elements.
styleInline CSS (use sparingly — prefer a stylesheet).
titleTooltip text on hover.
hiddenHides the element.
langLanguage of the element's content.
data-*Custom data attributes, e.g. data-user-id="7".
